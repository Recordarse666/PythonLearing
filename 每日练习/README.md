# 每日练习 · 28天 Python 熟练度训练

## 使用方法

1. 用 PyCharm 打开 `Project3` 项目（就是你现在的项目）。
2. 每天打开「每日练习 → 第X周 → DayXX_主题 → 题目.py」，在文件里直接写代码。
3. 做完自己运行验证，再打开 `每日练习_答案` 文件夹对照参考答案。
4. **先自己写，写不出来再看答案** —— 直接抄答案等于没练。

## 目录结构

```
Project3/
├── 每日练习/            ← 题目（每天一个文件夹，在这里写代码）
│   ├── 第1周_语法基本功/   Day01~Day07
│   ├── 第2周_函数与模块/   Day08~Day14
│   ├── 第3周_面向对象/     Day15~Day21
│   └── 第4周_实战整合/     Day22~Day28
└── 每日练习_答案/        ← 参考答案（做完再看！）
    └── （与题目相同的周/日结构）
```

## 四周路线

| 周 | 主题 | 目标 |
|---|---|---|
| 第1周 | 语法基本功 | 变量、分支、循环、列表、字典、字符串 |
| 第2周 | 函数与模块 | 函数、参数、闭包、装饰器、推导式、生成器 |
| 第3周 | 面向对象 | 类、封装、继承、多态、类方法/静态方法 |
| 第4周 | 实战整合 | 文件、异常、综合项目（图书管理/通讯录/爬虫） |

## 每日建议

- 每天投入 30~60 分钟，每天 4~5 题。
- 做完一题就运行一次，报错先自己读错误信息。
- 每天的 Day07/14/21/28 是综合题，重点是串联一周知识。
- 卡住的题先试 15 分钟，再对照答案，看完答案后**关掉答案重写一遍**。
